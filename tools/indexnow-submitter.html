How IndexNow works

Faster discovery, not a ranking shortcut.

IndexNow is an open protocol: you send a list of new or changed URLs, and participating search engines share it with each other. It helps them find your changes sooner instead of waiting for the next crawl. Each engine still decides what to crawl, index and rank.

Google is not listed as an IndexNow participant. For Google, keep your sitemap submitted in Search Console. Only submit URLs that are new, updated or deleted. Resubmitting unchanged pages again and again can trigger rate limits (HTTP 429).
What is IndexNow?

An open protocol that lets a website notify search engines about new, updated or deleted URLs with one request. A submission to the shared endpoint is passed on to all participating engines.

How do I submit my site to Bing?

Verify your site in Bing Webmaster Tools and submit your sitemap.xml there once. After that, use IndexNow for each page you publish or update: this tool sends those URLs to Bing straight away instead of waiting for the next crawl, and Bing shares them with the other IndexNow search engines.

Which search engines use IndexNow?

The IndexNow FAQ lists Amazon, Bing, Naver, Seznam.cz, Yandex and Yep. Submitting to one participant shares the URLs with the others.

Where do I upload the key file?

Upload your-key.txt to the root of the same host as your URLs, so it opens at https://example.com/your-key.txt and contains only the key. On Netlify, Vercel or a static host, place it in the folder that is published as the site root. On WordPress or cPanel hosting, upload it to the site's root folder, usually public_html.

Why does the key file check fail?

Common causes: the file is in a subfolder, the file name and key differ, the file contains extra text, the URL redirects to another host or protocol, or a firewall blocks automated requests. Open the exact address in a private browser window to confirm it shows only the key.

Does IndexNow guarantee indexing?

No. A 200 or 202 response only confirms the notification was received. Indexing and ranking still depend on each search engine and the quality of the page.

What does this tool send and store?

Your domain, key and URL list are sent through a small serverless relay, because browsers cannot call the IndexNow API directly. The relay checks your key file, forwards the request to api.indexnow.org and stores nothing. Your domain and key are saved in this browser for convenience; clear them with the Clear button.

Can I automate this?

Yes. IndexNow works well as a step after each deployment that submits only the pages changed in that release. That is how I run it on this site, and it is the kind of automation I build into client SaaS and marketing sites.
